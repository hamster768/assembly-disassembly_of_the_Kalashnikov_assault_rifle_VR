# assembly-disassembly_of_the_Kalashnikov_assault_rifle_VR
This VR simulator is designed to practice the skills of incomplete disassembly and assembly of the Kalashnikov assault rifle (AK-74) in strict accordance with the official "Manual on Small Arms".
